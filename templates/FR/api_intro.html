L'API ubiblio vous permet de demander des ouvrages et d'effectuer des recherches, en obtenant des résultats au format JSON plutôt qu'en HTML. Pour l'utiliser, vous devrez créer une clé API. Cette clé ne vous sera affichée qu'une seule fois et n'est pas stockée dans la base de données ; veillez donc à la copier dans un endroit sécurisé. Les points de terminaison (endpoints) de l'API sont les suivants:

  • Récupérer un livre par son ID: GET /api/bookDetails/{bookId}/{apiKey}
  • Récupérer un livre au hasard: GET /api/randomBook/{apiKey}
  • Récupérer les images de couverture d'un livre : GET /api/bookCoverImages/{bookId}/{apiKey}
  • Récupérer les 10 livres ajoutés le plus récemment : GET /api/recentBooks/{apiKey}
  • Statistiques de la bibliothèque : GET /api/stats/{apiKey}
  • Rechercher par auteur: GET /api/searchByAuthor
  • Rechercher par titre: GET /api/searchByTitle
  • Rechercher par titre ou par auteur (les deux doivent être indiqués): GET /api/searchByTitleOrAuthor

L'API de recherche exige que vous encodiez vos termes de recherche en URL. Les termes de recherche sont:

  • key : votre clé API
  • title : une chaîne de caractères à rechercher dans les titres. Désactivé en cas de recherche par auteur uniquement. Chaîne de caractères.
  • author : une chaîne de caractères à rechercher parmi les auteurs. Désactivé en cas de recherche par titre uniquement. Chaîne de caractères.
  • onlyEbooks : inclut uniquement les livres numériques dans les résultats de recherche, à l'exclusion des livres physiques. Booléen.
  • noEbooks : inclut uniquement les livres physiques dans les résultats de recherche, à l'exclusion des livres numériques. Booléen.
  • skip : les résultats sont limités à 10 éléments. Ce paramètre permet la pagination. Entier non signé.

L'API Stats attend que vous encodiez les termes suivants en URL, le cas échéant. Seul votre clé API est obligatoire :

  • key : votre clé API
  • isSum : définissez 'True' si vous additionnez les valeurs de tous les éléments d'un groupe. Définissez 'False' si vous souhaitez uniquement les compter.
  • group : champ selon lequel regrouper les résultats. Par défaut : genre.
  • target : champ à additionner au sein des groupes. Applicable uniquement si isSum = True. Par exemple, vous pouvez définir la target=ISBN et regrouper par genre. Cela additionnera tous les ISBN et vous donnera le résultat par genre (oui, c'est inutile, mais cette fonctionnalité est principalement destinée aux champs personnalisés).

    • Exemple: GET https://your-ubiblio.com/api/searchByTitleOrAuthor?key=f4816607-8d3a-4e73-83d5-225ef4e16db9&title=Alice&author=Lewis&onlyEbooks=False&noEbooks=False&skip=0

    Lors de la récupération des images de couverture, ubiblio ne renvoie que le nom du fichier. Vous devrez effectuer une requête distincte via HTTP GET, par exemple vers [ubiblioURL]/static/bookImages/[nom_du_fichier].

    Si vous perdez votre clé API, vous devrez la réinitialiser. Pour créer ou réinitialiser votre clé API, cliquez sur le bouton ci-dessous.
