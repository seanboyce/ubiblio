Exportation de la Liste de Livres

Il s'agit de listes de livres uniquement ; par exemple, si vous souhaitez transférer plusieurs livres d'une bibliothèque uBiblio à une autre. Ou si vous souhaitez simplement un fichier CSV de vos livres que vous pourrez ouvrir avec d'autres applications.


La restauration à partir de l'un de ces fichiers n'effacera pas la base de données actuelle. Elle ajoutera tous les livres du fichier à la base de données actuelle. Il est généralement conseillé de sauvegarder la base de données avant de procéder à cette opération.

Téléverser une Backup

Cette fonction accepte les backups de bases de données, les backups de fichiers et les exportations de listes de livres. Vous pouvez donc l'utiliser pour fusionner des bibliothèques, migrer vers un nouveau serveur ou passer à une version plus récente de l'application.
