The ubiblio API allows you to request books and make searches, with JSON results instead of HTML. To use it, you will need to create an API key. Your API key will be shown to you only once, it is not stored in the database, so be prepared to copy it comewhere secure. The API endpoints are as follows:

  • Fetch a book by ID: GET /api/bookDetails/{bookId}/{apiKey}
  • Fetch a random book: GET /api/randomBook/{apiKey}
  • Fetch the 10 most recently added books: GET /api/recentBooks/{apiKey}
  • Fetch the cover images for a book, if any: GET /api/bookCoverImages/{bookId}/{apiKey}
  • Library stats: GET /api/stats/{apiKey}
  • Search by author: GET /api/searchByAuthor
  • Search by Title: GET /api/searchByTitle
  • Search by Title or Author (both need to be specified): GET /api/searchByTitleOrAuthor

The search endpoints expect you to URL-encode any search terms. The search terms are:

  • key: your API key
  • title: a string to search for in titles. Disabled if searching only by author). String.
  • author: a string to search for in titles. Disabled if searching only for titles. String.
  • onlyEbooks: Only include ebooks in the search results, not physical books. Boolean.
  • noEbooks: Only include physical books in your search results, not ebooks. Boolean.
  • skip: Results are limited to 10 results. This lets you paginate. Unsigned integer.

The Stats endpoint expects you to URL-encode the following terms as needed. None are required except your API key:

  • key: your API key
  • isSum: Set to True if you are adding the values of all elements within a group. False if you want to count them only.
  • group: What field will you group results by? Defaults to genre.
  • target: What field will you sum within groups? Only applicable if isSum=True. For example, you can set the target to ISBN, and group by genre. This will add together all the ISBNs and give you the result by genre (yes, this is useless, but the feature is mainly for custom fields.)

    • Example: GET https://your-ubiblio.com/api/searchByTitleOrAuthor?key=f4816607-8d3a-4e73-83d5-225ef4e16db9&title=Alice&author=Lewis&onlyEbooks=False&noEbooks=False&skip=0

    When fetching cover images, ubiblio returns the filename only. You'll need to fetch separately via HTTP GET, e.g. to [ubiblioURL]/static/bookImages/[filename]

    If you lose your API key, you will need to reset it. To create or reset your API key, click the button below.
